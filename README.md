# Hangarin

## Project Description
Hangarin is a simple web application built with **Django** that helps users organize their daily tasks, manage priorities, add notes, and break down large goals into smaller subtasks. It is designed to make productivity more manageable and structured.

## Features
- Create and manage tasks with deadlines
- Assign priorities (High, Medium, Low, Critical, Optional)
- Categorize tasks (Work, School, Personal, Finance, Projects)
- Add subtasks to break down larger goals
- Attach notes to tasks
- Track task status (Pending, In Progress, Completed)
- Admin interface with filters and search functionality

## Requirements
- Python 3.x
- Django
- Faker (for generating sample data)
- Virtual environment (recommended)
